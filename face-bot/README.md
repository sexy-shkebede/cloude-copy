# I WANNA MOG YOU — Telegram-бот оценки внешности

Бот размечает лицо по 68 точкам, считает пропорции (трети, пятые, симметрию, наклон глаз,
нос, губы, скулы, челюсть) и анализирует профиль 90° (угол лоб–нос, носогубный угол, выпуклость
профиля, E-линия Рикеттса). По каждой части лица ставится балл, затем итоговая оценка 1–10.

Всё считается **локально на телефоне** (OpenCV), без платных нейросетей и внешних API.

## Возможности

- `/start` — приветственная картинка (`assets/banner.jpg`) и выбор: **📱 Мини-приложение** (пока заглушка) или **📸 Оценить в чате**
- пошаговый сценарий: пол → фото анфас → фото в профиль (90°) → результат
- результат: карточка с итоговым баллом, разлиновка лица на фото, разметка профиля и подробный разбор
  по каждой части лица с советами
- баланс оценок, покупка за **звёзды Telegram** (1 оценка = 10 ⭐, пакеты 1/3/5/10)
- оценка списывается только после успешного анализа; если фото не подошло — бот попросит другое бесплатно
- **🏆 Топы** — три вкладки по 10 мест: по рейтингу, по оценкам на балансе и топ кланов.
  Рейтинг человека — его **лучшая** оценка. В топе по рейтингу можно нажать на место
  и посмотреть фото, за которое человек его получил (анфас, профиль и карточка результата)
- **🛡 Кланы** — каждый может создать один клан и вступить в любой другой; рейтинг клана —
  сумма рейтингов всех участников. Глава может распустить клан, участник — выйти или перейти в другой
- все оценки, результаты и фото хранятся на телефоне (см. «Где хранятся данные»)
- админ (ID `7185631660`) выдаёт и забирает оценки, смотрит статистику, делает возвраты звёзд,
  оценивает себя бесплатно, модерирует топ и кланы

## Установка в Termux (Android)

1. Установи **Termux из F-Droid** или с GitHub (версия из Google Play устарела и не работает).
2. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
   Для оплаты звёздами ничего подключать не нужно — Stars работают у всех ботов.
3. В Termux скачай код:
   ```bash
   pkg install -y git
   git clone https://github.com/sexy-shkebede/cloude-copy.git
   cd cloude-copy/face-bot
   ```
4. Запусти установку (поставит Python, OpenCV, Pillow и скачает модели ~55 МБ; займёт 5–15 минут):
   ```bash
   bash setup_termux.sh
   ```
5. Впиши токен в файл настроек:
   ```bash
   nano .env        # строка BOT_TOKEN=123456:ABC...   (сохранить: Ctrl+O, Enter, выйти: Ctrl+X)
   ```
6. Запусти бота:
   ```bash
   bash run.sh
   ```
   Скрипт включает `termux-wake-lock` (чтобы Android не усыплял Termux) и перезапускает бота при сбоях.

### Чтобы бот работал постоянно

- В настройках Android отключи **оптимизацию батареи** для Termux.
- Можно запускать в `tmux`, чтобы закрыть окно Termux и не остановить бота:
  `pkg install tmux`, затем `tmux new -s bot`, внутри `bash run.sh`; отсоединиться — `Ctrl+B`, потом `D`;
  вернуться — `tmux attach -t bot`.
- Автозапуск после перезагрузки телефона — приложение **Termux:Boot**.

### Проверка без Telegram

Можно проверить анализ на своих фото до запуска бота:
```bash
python selftest.py анфас.jpg профиль.jpg m     # m — мужчина, f — женщина
```
Картинки результата появятся в папке `selftest_out/`.

## Команды

Для всех: `/start`, `/rate` (оценить), `/top` (топы), `/clan` (кланы), `/balance`, `/buy` (купить оценки),
`/help`, `/paysupport`, `/terms`.

Для админа:

| Команда | Что делает |
|---|---|
| `/give 123456789 5` | выдать 5 оценок по ID (можно `@username`, если человек уже запускал бота) |
| `/take 123456789 2` | забрать 2 оценки |
| `/user 123456789` | баланс, оценки и последние оплаты пользователя |
| `/stats` или `/admin` | статистика бота |
| `/refund CHARGE_ID` | вернуть звёзды за платёж (ID приходит админу в уведомлении об оплате) |
| `/unrate 123456789` | убрать лучшую оценку человека из топа (например, прислал чужое фото); рейтингом станет следующая по величине |
| `/delclan 12` | удалить клан по номеру или точному названию (номер админ видит в карточке клана) |

Подсказка: перешли боту любое сообщение пользователя и ответь на него `/give 5` — ID подставится сам
(если у человека не скрыта пересылка в настройках приватности).

|---|---|---|

| `PRICE_STARS` | `10` | цена одной оценки в звёздах |
| `WELCOME_BONUS` | `0` | бесплатные оценки новым пользователям |
| `ADMIN_IDS` | — | дополнительные админы через запятую (`7185631660` — админ всегда) |
| `ADMIN_FREE` | `1` | админы оценивают себя бесплатно |

| `DATA_DIR` | `data` | папка с базой, фото оценок и логом |

## Топы и кланы

- **Рейтинг человека** — его лучшая оценка за всё время. При равном балле выше тот, кто получил его раньше.
- **Рейтинг клана** — сумма рейтингов всех участников (у кого ещё нет оценки, приносит 0).
- В каждом топе 10 мест, внизу человек видит своё место. Под топом по рейтингу кнопки 🥇🥈🥉4…10 —
  они присылают фото анфас, профиль и карточку результата той оценки, за которую дано место.
- Фото с лучшей оценкой видят другие, пока человек в топ-10. Скрыть его можно в «💰 Баланс» →
  «🙈 Скрыть фото из топа» (об этом сказано в инструкции к фото и в `/terms`).
- Клан: название 2–24 символа (буквы, цифры, пробелы, эмодзи), названия не повторяются без учёта регистра.
  Один человек — один свой клан; распустив его, можно создать новый. Состоять можно только в одном клане:
  при вступлении в другой бот спросит подтверждение. Глава не может выйти, только распустить клан.
  Когда кто-то вступает, главе приходит уведомление.

## Где хранятся данные

Всё лежит на телефоне в папке `face-bot/data/`:

| Что | Где |
|---|---|
| пользователи, баланс, платежи, все оценки с баллами по каждой части лица и замерами, кланы | `data/bot.db` (SQLite) |
| фото анфас, профиль и карточка результата каждой оценки | `data/photos/<ID пользователя>/<номер оценки>_front.jpg`, `_side.jpg`, `_card.jpg` |
| лог работы | `data/bot.log` |

Фото сохраняются уменьшенными (до 1280 px, ~100–300 КБ на оценку). Старая база от прошлой версии
бота обновляется сама при запуске, ничего переносить не нужно; у оценок, сделанных до обновления,
фото нет — в топе бот так и скажет.

Резервная копия (остановив бота): `termux-setup-storage`, затем
`cp -r ~/cloude-copy/face-bot/data ~/storage/downloads/facebot-backup`.
Папку можно перенести и через переменную `DATA_DIR` в `.env`.

## Приветственная картинка

После `/start` бот показывает `assets/banner.jpg`. Чтобы поменять её, замени файл на свой
(JPG или PNG до 10 МБ, удобнее всего 16:9) или укажи другой путь в `BANNER_PATH`.
Цена «1 оценка = 10 ⭐» нарисована прямо на картинке, поэтому при смене `PRICE_STARS` обнови и её.
После замены картинки перезапусти бота — до перезапуска Telegram показывает уже загруженную.
Если файла нет или Telegram его не принял, бот нарисует баннер сам — с актуальной ценой.

## Как получить хороший результат

- **Анфас:** смотреть прямо в камеру, камера на уровне глаз, ровный свет, открытый лоб, без очков.
- **Профиль:** строго боком (виден один глаз), **однотонный фон** за лицом, волосы за ухом.
  Густая борода и усы скрывают губы и подбородок — углы профиля в этом случае менее точные.

## Как устроен анализ

- `analyzer/frontal.py` — детектор YuNet находит лицо и 5 опорных точек, лицо выравнивается,
  затем модель LBF ставит 68 точек; линия роста волос ищется по цвету кожи над бровями.
- `analyzer/profile.py` — линия профиля строится по контрасту с фоном (быстро), а если не вышло —
  через GrabCut; на линии ищутся глабелла, переносица, кончик носа, основание носа, губы и подбородок.
- `analyzer/scoring.py` — идеальные диапазоны (отдельно для мужчин и женщин), баллы, комментарии и советы.
- `graphics/` — все картинки (баннер, инструкции, разлиновка, карточка результата, баланс, шапки топов и кланов).
- `bot.py` — логика бота, `database.py` — SQLite (`data/bot.db`): пользователи, баланс, платежи, история оценок,
  кланы и топы.

Оценка — геометрический анализ в развлекательном формате, а не медицинское заключение.

## Частые проблемы

- **`В установленном OpenCV нет модуля cv2.face`** — поставь OpenCV из репозитория Termux:
  `pkg install x11-repo && pkg install opencv-python` (не через pip).
- **`Не найдены модели`** — запусти `python download_models.py` (нужен интернет, ~55 МБ).
- **`Conflict: terminated by other getUpdates request`** — бот запущен дважды (например, на телефоне и на ПК).
- **Запуск на ПК/сервере:** `pip install -r requirements-pc.txt`, `python download_models.py`, `python bot.py`.
