# Канон: сайт новостей луксмаксинга

Статический сайт без фреймворков и сборщиков: готовые HTML-страницы лежат в папке `docs/`,
а их исходники (тексты и генератор) в папке `site/`. GitHub Pages умеет раздавать папку `docs/` напрямую.

## Как опубликовать на GitHub Pages

1. Репозиторий должен быть **публичным** (на бесплатном тарифе Pages работает только для публичных).
2. На GitHub откройте репозиторий → **Settings** → **Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
4. **Branch:** ветка с сайтом (`main` после слияния или текущая рабочая ветка), папка **`/docs`** → **Save**.
5. Через 1-2 минуты сайт откроется по адресу `https://mogg.shkbd.su/`.

### Свой домен

Сайт живёт на домене `mogg.shkbd.su`. Домен записан в файле `docs/CNAME` (одна строка с адресом):
GitHub Pages берёт его оттуда, а в **Settings** → **Pages** → **Custom domain** стоит тот же адрес
с галочкой **Enforce HTTPS**. В DNS у поддомена нужна запись `CNAME` на `sexy-shkebede.github.io`.
Генератор `docs/CNAME` не трогает и не удаляет, но не стирайте его, когда заменяете папку `docs/` вручную.

Если адрес сайта сменится, поменяйте `docs/CNAME` и поле `"url"` в `site/content/site.json`
и пересоберите сайт: от `"url"` зависят превью ссылок в Telegram и VK и ссылки на странице 404.

## Как добавить или изменить новость

1. Откройте `site/content/articles.json` и добавьте объект по образцу существующих:
   `slug` (латиница, для адреса страницы), `title`, `category`, `date` (`ГГГГ-ММ-ДД`), `author`,
   `dek` (подзаголовок), `summary` (текст для карточки) и `blocks`: абзацы `p`, подзаголовки `h2`,
   цитата `quote` с полем `cite` и список `ul` с полем `items`.
2. Положите картинки в `docs/assets/img/`: `{slug}-p600.webp`, `{slug}-p1200.webp` (4:5),
   `{slug}-l750.webp`, `{slug}-l1500.webp` (3:2) и обложку для превью `docs/assets/og/{slug}.jpg` (1200×630).
   В `site/content/site.json` → `images` добавьте подпись к фото (`caption`) и номер работы в коллекции
   The Met (`met`), если это музейный снимок. Необязательно: `alt` (описание картинки для незрячих,
   по умолчанию берётся подпись) и `credit` (источник после подписи; по умолчанию The Met, `""` убирает его).
   Картинки без `met` не попадают в список музейных карточек на странице «О проекте».
3. Пересоберите сайт и закоммитьте папку `docs/`:
   ```bash
   python site/build.py
   ```
   Нужен только Python 3.8+ без дополнительных пакетов (работает и в Termux).

Генератор не пропустит длинное тире «—» и короткое «–» в текстах: по правилам дизайна сайта вместо них
используются двоеточие, запятая или точка. Неразрывные пробелы после коротких слов он расставляет сам.

## Что внутри

- **Шрифты:** Source Serif 4 (заголовки и текст статей, с засечками) и Geist (интерфейс). Это открытые
  аналоги фирменных Anthropic Serif и Anthropic Sans: те закрытые и без публичной лицензии, поэтому
  класть их в публичный репозиторий нельзя. Файлы лежат локально в `docs/assets/fonts` (SIL OFL).
- **Иконки:** Phosphor (MIT), урезаны до используемых значков.
- **Фото:** скульптуры из открытой коллекции The Met (Open Access, CC0). Исключение: главная картинка
  эксперимента, это иллюстрация I WANNA MOG YOU.
- **Тема:** светлая и тёмная, по умолчанию как в системе, переключатель в шапке.
- **Анимации** уважают системную настройку «уменьшить движение».
- **Эксперимент** с античными головами настоящий: их прогнали через алгоритм бота из папки `face-bot/`.
  Остальные новости, люди и компании вымышлены, это указано в подвале и на странице «О проекте».
